# Netflix-Recommendation-System-Project-2026_Akanksha_25114055

A machine learning-based recommendation model built using the Netflix Prize Dataset to generate personalized movie recommendations and predict user ratings.

## Overview
This project explores recommendation system techniques for personalized content discovery. The system learns user preferences from historical movie ratings and recommends relevant movies to users.

## Dataset
Netflix Prize Dataset

- 100M+ ratings
- 480K+ users
- 17K+ movies
- Rating scale: 1–5

Dataset: https://www.kaggle.com/datasets/netflix-inc/netflix-prize-data

## Features
- Exploratory Data Analysis (EDA)
- User and movie behavior analysis
- Rating prediction
- Top-K recommendation generation
- Model comparison
- Performance evaluation

## Models Implemented
1. Item-Based Collaborative Filtering
2. Matrix Factorization (SVD)

## Evaluation Metrics
- RMSE (Root Mean Squared Error)
- MAP@10 (Mean Average Precision @ 10)
